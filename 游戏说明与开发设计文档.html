一、游戏概述

《旋刀录》是一款以“环绕武器自动攻击”为核心的三幕路线 Roguelite。玩家通过随机路线、金币商店、构筑牌和 Boss 遗物形成流派。

单局目标是连续完成三幕。每幕拥有 13～15 行随机路线和一名幕主，第三幕幕主是最终 Boss。

游戏强调三种体验：

  1. 操作简单但站位有深度：攻击自动进行，玩家专注走位、聚怪和拾取金币。
  2. 路线风险明确：普通战积累金币，精英提供紫牌，商店和事件修正构筑。
  3. 成长爽感清晰：武器数量、尺寸、转速、刀气、元素连锁和死亡效果都会随构筑逐渐强化。

三、核心游戏循环

一局游戏由以下循环构成：

  1. 选择角色并完成本幕开场三选一。
  2. 在每幕 13～15 层由下向上的羊皮路线图中选择相连节点；五条主路径自然汇合和分叉，每层通常出现 2～4 个节点。
  3. 第一幕普通战进入按节点种子生成的不规则房间，封门清除三波敌军并拾取金币。
  4. 精英战在 90 秒内斩杀目标并选择紫牌。
  5. 在商店购买六张随机牌，或访问休息点和事件。
  6. 在 120 秒内击败幕主；前两幕选择 Boss 遗物，第三幕胜利后通关。

敌人不再提供经验。右上角钱袋在远征期间固定显示金币；买不起的商店卡牌会置灰并显示差额。精英、事件、休息与普通战会展示实际奖励结算，确认后才返回路线。新远征使用稀疏多路径地图，每个节点通常只有一至两条出口；旧存档继续使用原四列拓扑。路线、商店、待选奖励、结算单和节点状态会自动保存；死亡或超时结束本局。

第一幕普通战使用略大于一个视口的随机不规则单房，镜头在房间内跟随；三波敌军分别生成24、32和42只。高墙采用按朝向自动拼接的古风像素样式，由青灰石砖、暗青瓦檐、朱红木构和暖金包角组成，房间上沿设有分层山门门楼；装饰与碰撞继续读取同一份墙体地块。其他现有精英、幕主以及第二、第三幕继续沿用当前场地和限时配置。正式支持目标为 Windows 桌面键鼠。

五、武器与战斗系统

三个角色拥有不同武器造型、轨迹和打击声音：

  • 玄刃使用宝剑，音色清亮均衡。
  • 影刃使用细长双枪，音色短促尖锐。
  • 镇岳使用厚重大刀，音色低沉有重量感。

飞刃天机、离心飞刃等技能会沿用当前角色的武器模型。玄刃飞出宝剑、影刃飞出长枪、镇岳飞出大刀，不使用统一的通用飞剑图片。

基础伤害流程：

  1. 武器与敌人发生碰撞。
  2. 检查该武器对该敌人的命中冷却。
  3. 计算暴击，暴击率最高按 95% 处理。
  4. 伤害乘以暴击倍率和全局伤害倍率。
  5. 根据流派附加元素、击退、吸血、处决或其他效果。
  6. 敌人死亡后生成对应死因的清晰死亡表现和经验。

玩家受到伤害时采用固定减伤：

实际伤害 = max(1, 敌人伤害 - 玩家护甲)

普通受伤后获得 0.72 秒无敌时间，防止高密度敌群在同一帧连续扣除全部生命。

卡牌拥有权重。刀数、伤害和转速等基础牌更常见，流派机制牌和元素牌更稀有。确定流派后，与流派标签匹配的卡牌权重会提高约 2.8 倍，使构筑更容易成型，同时仍保留少量跨流派选择。

当普通卡池耗尽时，无尽强化会兜底：

  • 无尽锋芒：伤害 ×1.12。
  • 无尽血气：最大生命 +12，并恢复 18。
  • 无尽疾行：移动和旋转速度 ×1.06。

因此 20 级后仍能持续成长，不会出现升级但无牌可选的情况。

七、六大核心流派

玩家在 5 级选择核心流派。10、15、20 级分别从该流派的三条分支中选择一次专属超级构筑。

1. 万刃宗

核心：刀数、双环、转速和残影。

选中后立即获得 2 把刀、12% 转速和一层反向内环。三条分支为：

  • 万刃路线：七星刀阵 → 百刃朝宗 → 万刃归宗。
  • 旋风路线：阴阳轮转 → 三重风眼 → 无尽刃轮。
  • 残影路线：留影刀痕 → 千层残月 → 时隙刀域。

玩法目标是扩大持续接触面积，用多层刀环和残影覆盖怪潮。缺点是单次打击较轻，面对高生命敌人时更依赖伤害与命中间隔成长。

2. 巨刃修罗

核心：自动发射修罗巨刃、巨刃数量、范围、频率、暴击和吸血。

选中后不会改变常驻环刃的数量与基础伤害，而是解锁独立的修罗巨刃发射器。初始每 4.55 秒朝最近敌人的方向发出一道贯穿型巨刃，范围约 177 px，单次伤害约为基础伤害的 4.1 倍。

修罗巨刃采用放大版圆月刀气的月牙轮廓，并叠加血金外辉、白色刃芯、多层残像、刃尖高光与火花。巨刃向前飞行并贯穿路径上的敌人，专属成长可增加同时发射的巨刃数量。

三条分支为：

  • 巨刃路线：破军巨刃 → 裂空双刃 → 修罗天刃。
  • 血月连斩：圆月连斩 → 血月追魂 → 天外断界。
  • 饮血路线：饮血狂刀 → 修罗血海 → 不死魔刃，在提高暴击与吸血的同时专门强化巨刃伤害。

修罗巨刃初始冷却为 4.55 秒。“巨刃蓄势”和血月分支会直接缩短冷却，最低为 1.7 秒；冷却、范围和伤害分别成长，卡片展示的每项增幅不会附带未说明的隐藏提升。

玩法目标是通过走位调整发射方向，让低频但极强的巨刃覆盖整列怪潮。弱点是巨刃攻击空档明显，需要用常驻环刃维持近身防线。

3. 飞刃天机

核心：追踪飞刃、弹射、远程刀气和雷电连锁。

选中后获得 2 级飞刃、1 次弹射并开启圆月刀气。飞出的武器继承角色当前武器样式。

三条分支为：

  • 飞刃数量：三才飞刃 → 天罗刃网 → 无量飞剑。
  • 弹射雷网：折光弹射 → 九曲追魂 → 雷霆天网。
  • 远程刀气：破空刀气 → 万里追风 → 虚空刃潮。

玩法目标是降低贴身战斗风险，依靠自动追踪清理分散敌人。对单体目标需要通过弹射、雷电或全局伤害补强。

4. 五行刀尊

核心：异常叠层、元素连锁和组合反应。

选中后立即获得烈火与雷霆，元素强度 +2，连锁次数 +1。

三条分支为：

  • 火雷路线：火雷共鸣 → 爆燃雷狱 → 九霄劫火。
  • 冰血路线：冰血相融 → 碎骨寒轮 → 极寒绞杀。
  • 毒火路线：毒火蚀骨 → 腐界毒云 → 万毒焚天。

元素触发具有鲜明视觉和声音：雷电使用黄色连锁闪电与电击声；火焰产生爆燃和火环；冰冻形成冰晶和冻结轮廓；剧毒产生绿色腐蚀烟雾和毒焰。

5. 金钟护身

核心：恢复护盾、破盾爆炸、护甲、恢复和短暂无敌。

选中后获得金钟护盾、5 点护甲、每秒 1 点恢复和 30 点最大生命。护盾被打破时生成黄色钟型特效，对圆形范围内的敌人造成伤害，然后进入恢复冷却。

  • 恢复路线：金钟吐纳 → 周天回护 → 不灭金钟。
  • 震爆路线：震钟罡爆 → 八方钟鸣 → 天罡震界。

6. 一刀倾城

核心：单武器、单刀伤害、单刀体积，以及以降低转速为代价的诅咒强化。

选中后无论此前拥有多少武器，都会固定为 1 把常驻刀刃；基础伤害提高至 2.5 倍，刀刃体积提高至 1.7 倍。诅咒代价是旋转速度降低 28%。一刀倾城不会生成内层刀环，后续也不会再出现增加刀数或内层刀环的选项。

三条分支为：

  • 绝世锋芒：倾城一斩 → 绝世锋芒 → 一刀倾天下，专注提高单刀伤害。
  • 倾城巨刃：长锋照影 → 巨刃倾城 → 横刀断界，专注扩大唯一刀刃的体积。
  • 转速诅咒：敛锋蓄势 → 静刃藏锋 → 刹那倾城，进一步降低转速，换取更高伤害与更大体积。

该流派的玩法重点是预判刀锋轨迹，用缓慢但巨大的单次切割处理高生命目标。它的覆盖频率明显低于多刀流派，走位需要主动配合刀锋当前角度。

元素主要作用
烈火叠加燃烧，周期性造成持续伤害

主要元素反应：

  • 火 + 雷：触发爆燃火环，对周围敌人造成范围伤害。
  • 冰 + 雷：雷击附加短暂冻结控制。
  • 火 + 毒：提高燃烧和中毒层数，并出现毒焰特效。
  • 冰 + 血：配合极寒绞杀提高对重伤目标的处决能力。

雷电基础触发概率为 16% + 6% × 连锁等级。连锁范围约为 150 + 8 × 元素强度，单次连锁伤害约为基础伤害的 35% + 9% × 元素强度，再乘全局伤害倍率。

为了保持爽感同时避免声音和特效过载，各元素分别设置了极短的音效与视觉冷却。高频命中时会合并反馈，而不是每次碰撞都创建新的声音节点和粒子。

九、经验与等级数值

第一阶段升级所需经验为 65。之后使用以下成长公式：

需求经验 = floor(55 + 等级 × 26 + 等级² × 2.15)

20 级以后额外乘以：

1.1^(等级 - 19)

设计目的：

  • 前期升级快，让玩家尽早接触关键强化。
  • 5 级确定流派，避免构筑方向出现得太晚。
  • 10、15、20 级提供固定质变节点，形成明确阶段目标。
  • 20 级后用指数项放缓升级速度，避免后期卡牌和属性无限膨胀过快。
  • 每 5 级仍提供宗师精进，维持长期成长反馈。

经验掉落会被拆成最多 4 颗经验球，以控制场上对象数量。经验物体上限为 360，寿命为 28 秒。

敌人还会根据战斗时间和玩家等级提高生命、伤害与速度。3 分钟后进入明显的后期成长区间，普通怪和迅捷怪的生命增长幅度最高，避免高成型构筑完全失去压力。

普通敌人在 2 分钟后有概率成为精英。基础精英概率会从约 4% 随时间提高，最高约 16%。精英单位约获得更大的体型、4 倍生命、1.5 倍伤害和 5 倍经验，并可能掉落强化宝箱。

战场事件节奏

  • 第一次世界事件约在 70 秒发生，之后每 65～85 秒一次。
  • 命运神坛主要在约 95 秒和 300 秒出现。
  • 第一镇守者在 180 秒出现。
  • 第二镇守者在 360 秒出现。
  • 最终首领在 600 秒出现。

世界事件包括经验灵雨、精英狂潮、灵泉恢复和刀魂共鸣，使每局的中期节奏不完全相同。

十一、遗物、神坛与诅咒

镇守者会提供三选一遗物。遗物属于高影响、低频率奖励，例如：

  • 猎魔天眼：精英和首领低于 18% 生命时处决。
  • 不死玄玉：最大生命 +60，每秒恢复 +3。
  • 刀皇冠冕：所有伤害 +35%，暴击率 +15%。
  • 饕餮钱匣：经验 +60%，宝箱率提高至 5.5%。
  • 轮回古镜：强化内外刀环并增加 2 把刀。

命运神坛提供“收益 + 代价”的选择，例如增加伤害但失去生命、增加生命但降低转速，或提高速度但缩小武器。其作用是打破常规成长曲线，让玩家主动承担风险。

诅咒牌同样采用高风险高收益设计：

  • 修罗心：伤害 +70%，最大生命 -30%。
  • 狂风症：转速翻倍，单次伤害 -28%。
  • 巨灵禁术：尺寸与伤害大幅提高，移动速度降低。
  • 孤刀绝境：只保留一把刀，获得 3 倍伤害和更大范围。
  • 招灾之印：精英更多，经验增加，宝箱率由 1.1% 提高至 2%。

当玩家集齐特定能力时，还能形成万刃归宗、修罗天刃、雷霆追魂刃、焚天刀域、不灭金钟阵、极寒绞杀轮、血月轮回和无相魔刀等进化组合。

十二、死亡表现与视觉反馈

敌人的外形按功能区分：普通怪、迅捷怪、重甲怪、施法怪、镇守者、精英和首领具有不同轮廓与内部纹样。

死亡表现不会使用难以理解的随机特效，而是根据致死来源展示明确结果：

致死来源死亡表现
普通刀刃、飞刃、刀气斩切效果
巨刃重斩更宽、更强的断裂效果
暴击金色爆裂线
火焰灼烧与余烬
寒冰冰封与碎裂
雷电黄色电击纹路
剧毒绿色腐蚀与毒液
流血血痕散射
金钟爆炸金色钟震圆环

视觉设计的原则是让玩家能从死亡结果反推“是哪种能力完成了击杀”，同时避免死亡动画持续过久遮挡战场。

十三、成就系统

游戏包含 51 项持久化成就，分为七类：

  • 战斗：累计击杀、暴击击杀、元素击杀、巨刃击杀、首领击杀。
  • 生存：存活 1/3/5/10 分钟、开始局数、胜利次数。
  • 成长：等级、刀数、武器尺寸、速度和暴击率。
  • 流派：体验六大核心流派及全部流派。
  • 元素：获得每种元素及集齐全部元素。
  • 角色：三名角色分别出战和获胜。
  • 特殊：金钟爆炸、死亡效果收集、总经验和累计战斗时间。

成就数据保存在浏览器本地存储中。更换电脑、浏览器或清除浏览器数据后，记录可能不会保留。

十四、数值策划思路

1. 角色平衡采用“不对称等价”

三名角色不追求相同的初始 DPS，而是分别出售不同优势：

  • 玄刃出售稳定恢复与通用性。
  • 影刃出售高频输出和操作上限。
  • 镇岳出售防御容错和护盾联动。

角色强度需要从生命、移动、覆盖面积、实际接触率、被动和流派相性综合评估，不能只比较基础伤害。

2. 大部分输出成长使用乘法

伤害、转速、尺寸和冷却多采用乘法成长，让连续选择同一方向时产生明显的构筑质变。其代价是后期容易出现指数膨胀，因此敌人也按时间和等级双重成长，并设置 20 级后的经验指数项。

3. 防御采用固定减伤和短暂无敌

固定护甲对大量低伤害敌人非常有效，但对首领和高伤害单位不会完全失效或完全免疫。最低伤害固定为 1，保证玩家不能仅靠护甲成为永久无敌。

4. 流派节点固定，普通升级随机

5、10、15、20 级固定出现关键流派选择，保证玩家每局都能形成完整构筑；普通等级仍采用三选一随机卡牌，保留 Roguelite 的变化。

5. 稀有机制与基础属性分层

基础伤害、转速和生命等牌负责稳定成长；飞刃、双环、元素、重斩和金钟负责改变玩法。这样即使玩家未抽到理想机制，也不会完全失去战斗力。

6. 风险收益必须可感知

诅咒和神坛的收益足够大，玩家才有选择它们的理由；代价则必须在卡牌上直接写明，并能在操作或生存压力中立即感受到。

十五、开发思路与技术结构

项目使用 Vanilla JavaScript、ES Modules、Vite 和 Canvas 2D，不引入运行时前端框架或游戏引擎。

源码按职责拆分：

模块职责
main.js页面启动入口
game.js游戏状态、循环、战斗、升级、流派和 UI 协调
characters.js角色定义、初始属性和被动状态
sprites.js玩家与武器精灵缓存和绘制资源
audio.jsWeb Audio 音效、音量和静音状态
performance.js数组原地压缩、距离计算、帧统计和固定随机数
achievements.js成就定义、进度、持久化和界面
styles.css菜单、HUD、卡牌、暂停和移动端样式

开发原则：

  • 角色静态定义与单局运行状态分离，重开时完整清理。
  • 升级奖励和外部奖励分别排队，防止高等级连续升级丢失选项。
  • 武器造型使用高分辨率离屏 Canvas 缓存，放大时减少模糊和错位。
  • 角色资源加载失败时仍可使用程序化绘制造型，不阻止游戏启动。
  • 通过 window.__gameDebug 暴露可重复测试接口，而不把调试逻辑散布在 UI 代码中。

十六、性能设计

性能目标是现代四核桌面设备在高压场景下稳定接近 60 FPS。

主要优化手段：

  • 每帧只重建一次敌人空间网格。
  • 碰撞查询复用数组，减少临时对象和垃圾回收。
  • 热路径优先使用平方距离，避免大量 Math.hypot。
  • 敌人、粒子、弹丸、文本和特效使用原地压缩清理，避免连续 filter() 分配。
  • 仅绘制视口附近对象。
  • 玩家与武器静态图形使用离屏 Canvas 缓存。
  • 中低画质减少粒子、阴影、发光和绘制密度。
  • 页面不可见时暂停更新和音频，恢复时重置帧时间。

对象数量上限：

对象上限
敌人130
经验360

战斗文字220
敌方弹丸/斩击140
玩家投射物60
刀痕90
飞刃45
元素特效140
死亡特效18

自动画质采用带迟滞的三级策略：连续慢帧达到阈值才降档，连续稳定快速帧达到更长阈值才升档，避免在临界帧率附近反复跳变。

十七、音频设计

音频采用混合架构：角色命中、暴击、受伤、格挡、核心技能和强敌登场使用 assets/audio 中的短采样，并叠加像素风瞬态；升级、界面、拾取和元素反馈仍由 Web Audio API 实时合成。正式采样映射集中在 game-sfx-manifest.js，便于逐项替换。

采样通过可重叠的 HTMLAudioElement 音频池播放，并对变体施加轻微随机播放速率。普通命中每秒最多保留约 12 个逻辑事件，暴击、格挡、重技能和首领登场拥有更高优先级。界面继续提供 0～100% 总音量调节。

页面隐藏时合成音频会暂停，正在播放的采样会停止；重新回到页面后恢复。受浏览器自动播放策略影响，首次播放声音前需要玩家先点击页面按钮进入游戏。

十八、测试与质量保证

项目包含以下验证方式：

  • Vitest：角色初始值、被动触发与重置、音量、成就、帧统计和确定性随机数。
  • Playwright：选角、键盘操作、开始、升级、死亡、返回选角、桌面与移动布局。
  • 固定种子压力场景：130 敌人、360 经验、650 粒子、14 把刀、90 刀痕和 45 飞刃。
  • 调试接口：指定流派、元素演示、金钟演示、怪物死亡效果演示和性能统计。

便携分享版会把生产脚本与样式嵌入“打开游戏.html”，避开本地 file:// 环境对外部模块脚本的限制；角色徽记保留在 assets 文件夹中。

十九、后续迭代建议

优先级较高

  1. 为每个流派增加独立结算统计，例如元素伤害、金钟伤害和巨刃击杀。
  2. 增加局内构筑总览，允许暂停时查看所有强化等级和具体数值。
  3. 加入简单存档导入/导出，方便玩家跨浏览器保存成就。
  4. 根据实际玩家数据继续平衡影刃前期输出、巨刃后期爆发和金钟循环频率。

中长期方向

  1. 新增地图、环境障碍和不同首领。
  2. 增加角色专属升级牌和角色解锁目标。
  3. 增加难度等级、无尽模式和每日固定种子挑战。
  4. 将实时合成音效与少量高品质采样结合，增强打击层次。
  5. 若对象规模继续扩大，可评估 WebGL 渲染，但当前规模下 Canvas 2D 更简单且足够稳定。

二十、对外分享方式

将“旋刀录-便携分享版.zip”发送给玩家。玩家完整解压后，双击“打开游戏.html”即可运行，无需安装 Node.js，也不需要启动本地服务器。

分享时必须保留整个文件夹结构，不要只单独发送 HTML 或角色资源文件。

二十一、像素首页与角色选择

《旋刀录》首页与角色选择已经拆分为两个独立界面。首页提供继续游戏、开始游戏、成就和怪物图鉴入口；开始游戏进入单角色轮播选角，确认角色后才创建新远征。

已有远征存档时，进入选角不会修改存档；只有点击“开始远征”并确认覆盖后才清除旧进度。角色选择支持鼠标、方向键、数字键 1～3、Enter 和 Escape。

首页群像使用本地 assets/ui/home-hero.svg，项目目录和 localStorage 键保持旧值以兼容既有记录。
